# Analisis Dirty Cafe Sales

## Deskripsi Proyek

Proyek ini bertujuan untuk menganalisis data penjualan kafe menggunakan Python. Analisis dilakukan untuk memahami pola penjualan, mengidentifikasi produk yang paling banyak terjual, mengetahui metode pembayaran yang sering digunakan, serta mengevaluasi kualitas dataset.

## Tujuan Analisis

1. Mengetahui produk yang paling banyak terjual.
2. Mengidentifikasi tren penjualan berdasarkan waktu transaksi.
3. Mengetahui metode pembayaran yang paling sering digunakan pelanggan.
4. Mengevaluasi kualitas data sebelum analisis lebih lanjut.

## Tahapan Pengerjaan

1. Business Understanding
2. Data Understanding
3. Data Preparation
4. Exploratory Data Analysis (EDA)
5. Data Visualization
6. Insight dan Rekomendasi
